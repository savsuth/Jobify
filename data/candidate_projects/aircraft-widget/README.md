# Aircraft Widget

A small floating widget for macOS that displays what is flying near a set of coordinates at any given moment-a photo of the aircraft, its callsign, altitude, and distance from that point, along with a short written observation generated by an AI agent. The location is fully configurable, so the widget can track any airport or point on the map, not just one fixed place. It remains above your other windows and refreshes itself automatically every 30 seconds.

## How it works

- `adsb.py` (in the core folder) fetches nearby aircraft from airplanes.live within a set radius of your chosen coordinates, then filters out anything above the configured altitude ceiling, so only genuine arrivals and departures are shown, not high-altitude overflights.
- `planespotters.py` (in the core folder) retrieves a photo of the selected aircraft from Planespotters.
- `agent.py` (in the core folder) is the AI agent. It sends the flight's telemetry and aircraft metadata to Claude, which returns a brief, conversational observation, such as the airframe's age or its typical routes. This is what appears in the card alongside the flight details.
- `widget.py` (in the ui folder) brings everything together: a background thread handles the fetching so the widget remains responsive, while the card itself is a draggable, frameless PyQt6 window.
